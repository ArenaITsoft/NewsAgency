# NewsCraft Studio Pro (News Design Management Platform)

यह एक एडवांस सास-आधारित (SaaS-based) न्यूज़ और पोस्टर डिजाइन मैनेजमेंट प्लेटफॉर्म है, जिसे विशेष रूप से स्थानीय और राष्ट्रीय समाचार पोर्टलों के लिए विकसित किया गया है।

## 🚀 मुख्य विशेषताएं (Key Features)
- **40+ श्रेणियां**: ब्रेकिंग न्यूज़, स्थानीय समाचार, राजनीतिक, विज्ञापन, जन्मदिन बधाई आदि।
- **Autofill Engine**: खबर का विवरण एक बार दर्ज करें और सभी टेंपलेट में लाइव अपडेट देखें।
- **Interactive Canvas Editor**: लेयर लॉक/अनलॉक सिस्टम के साथ बिना कोडिंग के डिजाइन संपादन।
- **AI Assistant**: खबर के अनुसार सबसे बेहतरीन टेंपलेट और लेआउट का सुझाव।
- **High-Res Export**: JPG और PNG फॉर्मेट में हाई-क्वालिटी डाउनलोड।
- **Admin & RBAC**: सुरक्षित लॉगिन, भूमिका आधारित अनुमति (Role-Based Permissions) और ऑडिट लॉग।

## 🛠️ इंस्टॉलेशन और रन करने के निर्देश (Quick Start)

अपने कंप्यूटर पर टर्मिनल (Terminal) या कमांड प्रोम्प्ट खोलें और निम्नलिखित कमांड चलाएं:

```bash
# 1. प्रोजेक्ट फोल्डर में जाएं
cd newscraft-portal

# 2. डिपेंडेंसी इंस्टॉल करें
npm install

# 3. लोकल डेवलपमेंट सर्वर शुरू करें
npm run dev
